# Data

`hour.csv` is the hourly file of the **Bike Sharing Dataset** (Capital
Bikeshare, Washington D.C., 2011-2012), downloaded unchanged from the UCI
Machine Learning Repository: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

Licence: CC BY 4.0. Citation: Fanaee-T, H. & Gama, J. (2013). Event labeling
combining ensemble detectors and background knowledge. *Progress in
Artificial Intelligence*, 2, 113-127.
