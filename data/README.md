# Dataset source

Source: [UCI Bike Sharing](https://archive.ics.uci.edu/dataset/275/bike%2Bsharing%2Bdataset)

Citation: Fanaee-T, H. (2013). Bike Sharing [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5W894.

License: Creative Commons Attribution 4.0 International, as stated by UCI.

`hour.csv` is the original hourly CSV from UCI's downloadable archive. It contains 17,379 rows and 17 columns, from 2011-01-01 to 2012-12-31. The webpage's instance count differs; the row count here was checked directly against the downloaded file and its included readme.

The original dataset readme is preserved as `UCI_Readme.txt`. The historical weather observations are not archived weather forecasts.
