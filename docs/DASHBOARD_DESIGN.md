# Dashboard clarity redesign

Visual thesis: a calm, light reading surface with one teal accent, clear numbers, and amber used only to identify an unfavorable cost or missed opportunities.

Content plan: results first; interactive call policy second; model evidence, data explanations, and individual records progressively deeper. Preserve all grading views and keep technical tables in expandable sections.

Interaction thesis: the threshold updates the decision summary and plots together; explicit call-all/call-none/reset buttons explain the extremes; short result transitions and expandable details provide orientation, with reduced-motion support.

No model retraining or change to the saved evaluation. The UI threshold is displayed as a percentage; the model still uses probabilities from 0 to 1.
